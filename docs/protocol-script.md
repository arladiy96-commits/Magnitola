# Сценарии AutoLink USB — одна установка APK вместо сборки под каждый пакет

Сборка с поддержкой сценариев: [Actions run #39734180875](https://github.com/arladiy96-commits/Magnitola/actions/runs/39734180875).

## Как пользоваться

1. Отключить USB, запустить приложение.
2. В поле **«Сценарий обмена»** уже есть подтверждённая последовательность.
3. Нажать **«Запустить сценарий (без пересборки APK)»**.
4. На магнитоле открыть AutoLink, подключить USB к телефону.
5. Сценарий ждёт точного VERSION_REQUEST, отвечает, ждёт ID3, отвечает, ждёт ID4 и завершает отправки. Сырые RX пакеты продолжают логироваться.
6. При следующем шаге исследования заменить текст сценария в том же редакторе и снова нажать **«Запустить сценарий»**. Текст сохраняется в Preferences, даже после перезапуска приложения.

## Поддерживаемые команды

- `EXPECT 00 03 00 06 ...` — дождаться кадра, совпадающего с точной последовательностью.
- `PREFIX 00 03 ?? ?? 00 05` — дождаться кадра с префиксом и wildcard-байтами `??`.
- `SEND 00 03 00 04 00 04 08 00` — после совпадения предыдущего EXPECT/PREFIX отправить один указанный кадр канала 0. Длина в заголовке должна соответствовать длине кадра.
- `DONE` — закончить сценарий без дополнительных TX.
- Строки, начинающиеся на `#`, считаются комментариями.

Сценарий специально ограничен: до 12 отправок за одну USB-сессию, до 260 байт на команду, только простые кадры канала 0 (первые два байта `00 03`). Неизвестные сообщения **не** вызывают отправку. Сценарий нужно явно включить нажатием кнопки. Если порт уже открыт и первый кадр пропущен, надо физически переподключить кабель; открытие AOA идёт автоматически.

## Отдельно об изображении

Этот механизм **не транслирует экран**. Он устраняет повторные сборки на этапе согласования. Для первого видеокадра потребуется восстановить service discovery, выбор канала видео и упаковку H.264. Нужно получить реальный ответ магнитолы на discovery до реализации кодека и отдельного экрана. Нельзя обещать работу заблокированного телефона на Android 16 до теста.

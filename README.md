# Магнитола — AutoLink USB Probe

Экспериментальный Android-проект для исследования подключения смартфона **POCO (Android 16)** к автомобильной магнитоле с поддержкой AutoLink.

## Что уже реализовано

- Обнаружение **Android Open Accessory (AOA)** с производителем Sunplus, Inc. и моделью DVD.
- Проверка и запрос USB-разрешения.
- Открытие аксессуара и чтение **только входящих** данных (до 64 КиБ за сессию).
- HEX-лог полученных байтов, журнал событий USB и экспорт TXT.
- Автоматическая сборка debug APK в GitHub Actions.

**Безопасность:** приложение не отправляет команды магнитоле, не перепрошивает её, не подключается к интернету и не требует root. Это первый тест соединения, а не замена AutoLink.

## Скачать APK

1. Открой [GitHub Actions — Build USB Probe APK](../../actions/workflows/build.yml).
2. Выбери последний **успешный** запуск.
3. Внизу страницы, в разделе **Artifacts**, скачай AutoLinkUsbProbe-debug-apk.
4. Распакуй ZIP и установи app-debug.apk на POCO.

Либо запусти сборку вручную: **Actions → Build USB Probe APK → Run workflow**.

## Проверить с магнитолой — обновлённая диагностика после теста 10:38

1. Установи самый свежий APK из [Actions](../../actions/workflows/build.yml).
2. На магнитоле открой режим AutoLink. Временно исключи автоматический запуск оригинального AutoLink на POCO, чтобы он не перехватил USB.
3. Запусти **AutoLink USB Probe** на телефоне до подключения кабеля. В приложении нажми кнопку **«Автотест: пройти 2 известных шага»** (это явное разрешение отправить два строго заданных ответа, если магнитола их запросит).
4. **Полностью отсоедини USB-кабель от телефона на 5 секунд и подключи обратно.** Чтение запустится само по AOA ATTACHED — шаги 1/2 нажимать не нужно.
5. Если в логе увидишь `RX 10 байт`, далее автотест отправит VERSION_RESPONSE; после второго ожидаемого кадра — AUTH_RESPONSE. Все неожиданные сообщения сохраняются в логе, но на них приложение не отвечает.
6. Если появится `USB открыт 7 секунд, но RX = 0 байт`, не нажимай кнопки 3/4. Это значит **пока не поступило ни одного байта**, а не ошибку парсера. Проверь кабель/порт, что магнитола находится в AutoLink, и повтори физическое подключение.
7. Сохрани лог в файл и пришли его для анализа.

**Важно:** приложение само открывает AOA-порт, но не пытается перепрошить магнитолу или послать случайные команды. Автотест остаётся строго ограниченным двумя уже исследованными ответами. Новые этапы протокола ещё не реализованы.


## Технический стек

- Java, Android SDK 35 (minSdk 26), Android Open Accessory.
- Android Gradle Plugin 8.7.3, Gradle 8.9, JDK 17.
- GitHub Actions собирает assembleDebug.

## Следующие этапы

1. Получить лог реального подключения и определить последовательность согласования.
2. Документировать протокольные сообщения и транспорт видео/ввода, используя результаты анализа оригинального AutoLink.
3. Проверить передачу **собственного** тестового кадра и приём касаний.
4. Затем отдельно проектировать автомобильный интерфейс на виртуальном дисплее Android.

Независимая работа автомобильного экрана при заблокированном телефоне **пока не подтверждена** и требует испытаний на Android 16.
